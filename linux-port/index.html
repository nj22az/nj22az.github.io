Installation & adding the game to Steam

On Steam Deck, switch to Desktop Mode and open Konsole. Paste:

curl -fL --progress-bar https://raw.githubusercontent.com/nj22az/nj22az.github.io/main/johansson-world/install.sh -o /tmp/johansson-world-install.sh &&
sh /tmp/johansson-world-install.sh

The installer verifies the download and installs in your user account. No compilation, sudo or SteamOS system changes.

  1. Open Steam → Add a Game → Add a Non-Steam Game.
  2. Select Johansson World, or browse to ~/.local/bin/johansson-world.
  3. Leave forced Proton compatibility disabled and select a Gamepad controller layout.
  4. Return to Gaming Mode and launch.

Player guide / released Linux demo 0.2.14

What can I actually do?

This is a playable island-life preview: explore, talk, shop, take the ferry and step into the residents’ lives. It is an unfinished game, with a tested core and several less thoroughly checked side activities. This guide describes the published 0.2.14 download, including browser-world changes through 21 October 2026. Later browser changes require a separate integration.

First visit · Activities · Controls · Limitations · Test results

The important distinction

Available means the feature is present and connected in the released game. Checked means it has specific automated or local play-test evidence. Neither means every interaction has been verified on a physical Steam Deck.

The core movement, menus, character selection and saves have local controller tests. Native Ubuntu startup and disk saves passed. Disconnect and reconnect now have event-driven and polled recovery checks, including held buttons and a changed device index. There is no measured Steam Deck frame-rate or battery-life result yet.

A good first visit

  1. Start Exploring. The first-entry guide explains the controls. If it is night and you start in bed, press A or move the left stick to get up. A fresh save starts with ¥1,200; an existing save keeps its balance.
  2. Walk around the shopping street and harbour. Approach a door, resident or object and read the action shown at the bottom right. A performs that action. D-pad left/right cycles other nearby actions; B backs out, stands up or leaves a room when that action is available.
  3. Open the Town book with View ▣. Use Places, Homes or People to get directions. “Find person” follows a resident’s known location; a scheduled location is an estimate, not a guarantee that they are standing there. Directions mark a walking route. They do not immediately teleport you.
  4. Try one small activity. Buy a drink or snack at Sakura, order food at Sato Ramen, talk to Nhung about Tama, fish at the pier, or try the Star Port arcade cabinet. Opening hours, money and earlier quest steps can affect the available choices.
  5. Try another life. Open ☰ Menu → People and choose a resident. Go home from Island → Go home, then return to the street. Save before experimenting with a different resident.
  6. Try the existing ferry crossing. At Minato Port, ask Ms Ganaha or use the gangway/deck-hand prompt. The Minato Maru crosses to Kitano-jima; the current development fare is free. Follow the boarding and departure prompts, and use the return service to come home.
  7. Save your day. Open ☰ Menu → Island → Save, or press X while the pause menu is open. Settings → Save & quit asks for confirmation. Use the title’s Load menu to return to a named save.

At night, some residents are asleep and some businesses are shut. That is part of the schedule. Town book → Town tools → Settings contains Clock, Weather and Sound controls if you want to explore the demo under different conditions.

The things you can do in 0.2.14

The places listed in the demo’s Town book

Core destinations in the integrated source include the following. A place listing means there is a destination/route target; it does not certify a complete interior or activity set at every site.

  • Shopping and food: Sakura Shōten, Sato Ramen, Minato Izakaya, Front-Row Books, Higa Liquor, Nakamura Zenzai, Blue Coral and the Community Hall.
  • Town and harbour: Minato Port Terminal, Minato Harbour Park, Harbour Warehouse, Dock Electrical & Repair Workshop, Johansson Harbour Office, Minato School, Community Hall, Minato Clinic and Minato Police Station.
  • Further exploration: Umi-no-yu, Harbour Park and Kitano-jima, with its airport.

Source inventory verified for the integrated world; this is not a manual acceptance record for every destination on physical hardware.

Explore Minato, its shops, interiors and Kitano-jima

Walk or run through the town, enter accessible buildings, sit at available seats, inspect objects, read notices and use the walking map. The island includes residents’ routines, day/night lighting, weather, local ambient audio and the working harbour. First- and third-person views are available through Town book → Town tools → Settings → View.

The existing Kitano-jima destination and ferry are retained. Compact Minato, coordinated roads, 14 canonical households, the shared tropical home, Sakura office with internal stairs and the refined Shiosai houseboat are integrated from the browser world. No additional ferry island is introduced by this release.

Checked: actual player movement/look, startup, entering/leaving selected homes and contextual-label layouts. Included, with wider route testing still needed: every building approach, ferry boarding/deck walk and outward/return trip on physical Deck controls.

Play as the 26 named residents and visit their homes

☰ Menu → People selects a resident using their own character appearance. Each has an assigned home/bed and a saved position. Families and housemates share addresses. Go home returns to the selected person’s room; nighttime starts use their sleep schedule, so a night worker need not start asleep.

This is one shared save world, not 26 separate campaigns. Wallet, inventory, quest progress and much of the relationship/story state are shared. Per-resident state covers identity, home, position and personal disputes. Some older action descriptions still refer specifically to Johansson. Incidental scenery characters, animals and vehicles are not promised as playable characters.

Assigned bedrooms are present. A complete house-building, property-purchasing, housemate-management or universal furnishing system is not part of this release; nine surplus Minato dwellings have been removed, while historical home identities remain available for save migration.

Checked: every roster selection uses the matching character recipe; Thuan and Mai’s nighttime bed starts, getting up, Officer Mori’s night-work exception, returning from a home, and saved identity/settings across reload. Every bed and entrance has not been walked manually on a Steam Deck.

Talk, give presents, follow small stories and read your records

Approach residents for written conversations, everyday remarks and available favours. Eligible items can be offered as presents; conversations and favours feed friendship and diary records. The Field book tracks notes, money, carried items, visited places and progress. It links to the Diary, Pocket album and Konbini passport. Town book → Town tools → Residents opens records for supported profiles.

Two established favours unlock Town book shortcuts: bring Tama home for Nhung, and earn Chin’s workshop escort by scoring 3/3 at Star Port and walking with him. Until both are complete, use directions and walk. The Tama route is: ask Nhung, catch a fish, give it to Tama near the ramen stall, then return to Nhung.

Included in the released activity and progression code. Written conversations and pause/resume over a conversation have controller checks; the entire favour/relationship catalogue has not been replayed end to end on Deck.

Shop, eat, drink, fish and earn or spend town yen

Sakura has goods, a basket/counter checkout flow, hot snacks, receipts and stamp-card progress. Vending machines sell drinks; cans can be returned to the recycling box. Sato Ramen and Minato Izakaya have seating, orders, served food/drinks and conversations. Watch the prompt at your seat, and wait if the server is preparing an order.

At the pier, choose Cast line, wait for BITE and reel in promptly. Fish can be kept for a favour or offered for sale to the harbour master. Some catches depend on the time of day. Star Port is a three-round timing game: entry ¥100, and a perfect 3/3 round pays ¥250. These are game-currency transactions.

Umi-no-yu opens 10:00–22:00: pay ¥300, use the changing/bathing interactions, and try the available milk or massage-chair interactions. The exterior footbath follows the bath’s opening hours.

Included as existing game systems, with underlying source tests. The 0.2.14 console suite does not certify every shop, serving animation, fishing outcome or bath interaction on physical hardware. Menus, stock, opening hours and money can legitimately block a purchase.

Use the item Bag and Field book

☰ Menu → Island → Bag opens the actual item grid, with categories, search and item actions. Select a supported food or drink for its Eat/Drink action; printed models can be inspected. Typing a search may need the trackpad and Steam’s keyboard.

Y opens Bag, matching the pause-menu shortcut. Choose Field book inside Bag for notes, quest progress, the diary and photo album.

The controller run checks that Y and the pause-menu tile both open Bag, including after a controller reconnect.

Take photos, pose characters and try karaoke

D-pad up raises the pocket camera; A takes a photo and B lowers it. Kept photos are available through Field book → Pocket album. Town book → Town tools also contains Photo studio and Moves. Studio tools use the game’s character assets, poses and framing.

Minato’s karaoke offers a song, arrangement and performers, with editable lyrics and local saved song choices. The performance uses rhythmic text-to-speech; it is not guaranteed recorded singing. Voices and speech support depend on the device.

Included in the package, but photo editing, typing lyrics, Studio editing and karaoke have not completed the dedicated Deck controller acceptance path. Expect some pointer/trackpad and text-entry work; these are not all-console-button-certified activities.

Explore the ferry, airport, workshop and town documents

The existing ferry crosses to Kitano-jima, with passenger decks and crew/departure information. Town book → Town tools → Ferry departure & crew opens its operations view. Ferry machinery and operating panels are development systems; this is not a finished, unrestricted ship simulator.

Kitano-jima includes an airport counter with a scheduled Naha return-flight flow: buy a ¥800 ticket, check in and board when allowed. Heavy rain suspends flights. Naha currently provides a limited arrivals/return connection, not an open-world recreation of the city.

The workshop includes model selection/printing/collection and inspection systems. The Community Hall and shop records contain notices, receipts and other documents. Some tools are more like embedded educational/editor interfaces than finished handheld activities.

Present in the release source. A complete flight, workshop production run, every operating panel and return ferry trip have not been verified in the 0.2.14 Steam Deck controller suite. The external full motor strip-down and Erik’s routine open a new page, which the installed application blocks.

Keep everyday life peaceful, or deliberately provoke a rare quarrel

Regular conversations do not automatically start fights. Choose “Lose your temper…” and deliberately insult the same eligible resident repeatedly: three warnings precede a fourth insult starting a quarrel. Apologising or leaving avoids escalation. Tempers expire and a cooldown prevents immediate repeated fights.

Children cannot fight. Johansson, Thuan, Thao and Nhung do not fight one another. Personal quarrels pay no festival prize money. In a quarrel, the new Deck defaults are X punch, Y kick, hold A guard, B dodge and View leave; these actions follow your mappings.

Checked locally: warnings before the fight, the fourth-insult trigger, pause during the bout, leaving it, and no festival reward. The old recurring Harbour Festival invitation/button is removed from normal Linux play; developer smoke fixtures exercising old stages do not make those stages a promised player feature.

Controls includes sensitivity, dead zone, field of view, invert Y, walking camera motion, stick swapping, axis selection and button remapping. Assigning an already-used button swaps the conflicting assignment. Tap Back or press Menu to cancel an assignment; hold Back for one second only to assign that button deliberately. D-pad directions navigate menus independently of gameplay remaps. Down only toggles the HUD while exploring, never underneath a menu. Controller input hides the cursor; deliberate mouse movement or a click restores it. Symbols follow the reported Deck/Xbox/PlayStation/Nintendo controller, with a manual override. Unknown face buttons use a four-position diamond. Nintendo letters reflect the physical positions: bottom B, right A, left Y, top X; confirm/back are not silently swapped.

Steam Input can report a controller as a virtual Xbox pad, hiding the real hardware identity. Select the right symbol family manually if necessary. Rear paddles and trackpads do not have a dedicated in-game binding layer: configure them in Steam Input. Gyro aiming, haptics and a complete Steam Input action-set integration are not implemented here.

What does not work,
or is not finished?

  • Optional AI model download: Thuan’s free-text AI mode needs a separately downloaded model/runtime. The installed game blocks renderer internet requests and does not bundle that model. Treat this mode as unavailable in the standalone demo; use the written conversations. The update downloader is a separate allowed network path.
  • External pages and real-world checkout: new-window links and external navigation are blocked, including the full motor strip-down/routine links. Online shop/checkout and streaming services are not supported standalone features. Internet access for updates does not turn these on.
  • Complete pad-only operation: editor tools, item search, save naming/import/export and other file/text dialogs may need a pointer or Steam keyboard. The tested pause/exploration path is broader than the tested editor/file-dialog path.
  • Independent character economies or finished campaigns: selecting a resident does not give them a separate wallet, bag or quest log. Some scripts still use Johansson-specific wording. Not every resident has equally deep authored stories.
  • Work still in progress: the compact town, unified ground and consolidated homes are included. The independent ferry timetable remains a brief. Higa Liquor’s evening bench is not reliably occupied, and park tending routines are not fully connected. Assigned beds are not a complete property editor.
  • Removed activities: the bicycle minigame and Thuan’s storage-room minigame are retired. Decorative bicycles and ordinary shop routines can remain in the world.
  • Other platforms and online play: this archive is x86-64 Linux only. macOS/iPad/iPhone builds are planned; ARM handheld builds and multiplayer/co-op are not delivered. It uses the existing Chromium/Three.js renderer, not a new native graphics engine.
  • Loading measurements: local Mac/Chrome title readiness measured about 10.7 seconds before exact query filtering and 5.6 seconds after. This is not a Steam Deck benchmark. Cel shading and scenery are retained.
  • Performance guarantees: 60 FPS, battery life, suspend/resume reliability, every controller model and every text-heavy screen still need physical Steam Deck testing. “Runs on Linux” is not a Steam Deck Verified claim.

Saving, updates and getting unstuck

Use Island → Save or paused X before a ferry trip, changing residents or trying an editor. Named slots stay in the application profile, with disk snapshots and a previous backup. Title → Load contains saved games and Import a save file. Town book → Town tools → Player & save contains the export tools. Imports, names and file dialogs may be easier in Desktop Mode. This is local saving, not Steam Cloud or automatic synchronisation with the web game.

Updates need internet: ☰ Menu → Settings → Updates → download → Save & restart. 0.2.7 installed patch support. This and later releases can offer a smaller file patch from the immediately previous version when the engine matches; the menu shows patch/full package and MiB before downloading. Changed, added and removed files are checked against the complete target inventory before switching. A changed base, skipped version or engine upgrade uses the full package; an invalid patch leaves the installation unchanged. The terminal installer remains a complete install/repair download and prints its target version. Saves and the previous installation are retained. If the app was unpacked without the installer, the update screen may ask you to run the installer instead. Ordinary installed gameplay is offline.

If a prompt is missing, move closer, face the object and cycle nearby actions. Check opening hours and funds before treating a locked choice as a bug. Use B to back out; for an awkward interior or position, try Menu → Island → Go home. If needed, quit and load the last save. Preserve the save directory when reinstalling.

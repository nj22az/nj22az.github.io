Johansson World.
Your island, offline.

Walk the streets, meet the residents, visit the shops and sail aboard Minato Maru. Install the island on Steam Deck or a Linux PC and play without an internet connection.

Download the Linux edition

Standalone Linux application using the existing Three.js world. Steam Deck hardware performance acceptance remains pending.

Steam Deck · x86-64 Linux

Copy, paste, install

On Steam Deck, switch to Desktop Mode and open Konsole. Paste this command:

curl -fL --progress-bar https://raw.githubusercontent.com/nj22az/nj22az.github.io/main/johansson-world/install.sh -o /tmp/johansson-world-install.sh &&
sh /tmp/johansson-world-install.sh

The installer verifies the download and installs within your user account. No compilation, sudo or SteamOS system changes.

Add the game to Steam

  1. In Desktop Mode, open Steam → Add a Game → Add a Non-Steam Game.
  2. Select Johansson World. If it is not listed, Browse to ~/.local/bin/johansson-world.
  3. Leave forced Proton compatibility disabled and select a Gamepad controller layout.
  4. Return to Gaming Mode and launch.

The island comes with you

The world, character assets, ferry, interiors, shops, and Johansson Studio are installed locally. The game does not download its scenery while you play.

Your named save slots live in the application profile, with separate disk backups. Updating the application preserves progress.

Make yourself at home

☰ Menu → People lets you play as any of the 31 named residents. Each has a home and bed; families and housemates share addresses.

Night-time starts follow the resident’s sleep and work schedule. ☰ Menu → Island → Go home takes you back to your own address.

Explore at your own pace

Everyday island life stays peaceful. Deliberate repeated insults give warnings before a rare quarrel; you can apologise or walk away. Children cannot fight. Johansson, Thuan, Thao and Nhung do not fight one another.

The cycling and storage-room minigames are removed. Actions show their full labels, and Nights in both editions replace gecko beeps and the pulsing cricket recording with sparse natural textures.

Update from the game

Open ☰ Menu → Settings → Updates. When online, download the new build, then choose Save & restart.

Downloads are verified before switching versions. The previous installation is retained. Playing the installed island remains offline.

Controller guide

  • Left stick: walk · Right stick: look · A: interact · Y: inventory.
  • ☰ Menu: pause menu · B: back · View: town book.
  • D-pad down: hide or restore the HUD. Keyboard: F8 for HUD, F10 for pause.
  • Hold R2 to run · X to jump · R3 to level the camera · L2 to look closely.
  • ☰ Menu → Settings → Controls: remap buttons and sticks, adjust sensitivity and dead zone, or invert the camera.
  • In a quarrel: X punches, Y kicks, hold A to guard, B plus direction dodges. View leaves the stage.
  • Symbols automatically follow the reported controller: Steam Deck, Xbox, PlayStation or Nintendo. Unknown face buttons use a highlighted four-position diamond. Set a manual symbol override in Controls if needed.
  • These are the new Steam Deck defaults. Existing custom assignments stay saved; choose Use island controls to apply the new preset.
  • The pause menu includes Save and a confirmed Save & quit to Steam. L1/R1 changes sections; X quick-saves while paused.

Platform and troubleshooting

This release is for x86-64 Linux, including Steam Deck. It includes its own desktop runtime. Linux is the first development and testing platform. macOS, iPad and iPhone ports are planned; this download does not run on Apple devices or the ARM-based RG CubeXX.

Game files install under ~/.local/share/johansson-world/; application data and save backups normally live under ~/.config/Johansson World/. Custom XDG folders are respected. Keep your save directory when moving or reinstalling the game.

The browser edition remains an island showcase. In the browser, open Town book → Town tools → Player & save → Export save file. Import that file using Load → Import a save file in the installed edition.

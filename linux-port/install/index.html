Steam Deck · x86-64 Linux

Copy, paste, install

On Steam Deck, switch to Desktop Mode and open Konsole. Paste this command:

curl -fL --progress-bar https://github.com/nj22az/nj22az.github.io/releases/download/johansson-world-linux-v0.2.21/install.sh -o /tmp/johansson-world-install.sh &&
sh /tmp/johansson-world-install.sh

The installer verifies the download and installs within your user account. No compilation, sudo or SteamOS system changes.

Play from Gaming Mode

The installer adds Johansson World to your Steam Library by itself. If Steam is open in Desktop Mode, it closes it for a moment so the entry is kept. Then double-click Return to Gaming Mode: the game is in Library → Non-Steam, with its icon. It installs and selects Johansson World - Steam Deck: left stick and left trackpad move; right stick and right trackpad look. Right stick or right trackpad click centres the view.

Already installed? Apply the Deck layout

After upgrading the app from 0.2.20 or earlier, run this once in Konsole in Desktop Mode to apply the trackpad layout without downloading the game again. The in-game updater cannot change a running Steam client’s layout:

curl -fL --progress-bar https://github.com/nj22az/nj22az.github.io/releases/download/johansson-world-linux-v0.2.21/install.sh -o /tmp/johansson-world-install.sh &&
sh /tmp/johansson-world-install.sh --steam

Gaming Mode has no terminal, so the command is always run in Desktop Mode. Play from Gaming Mode: launched in Desktop Mode, Steam keeps its desktop controls. Leave forced Proton compatibility disabled and use the installed Johansson World - Steam Deck layout. If Steam has not been set up on this device yet, add it by hand: Steam → Add a Game → Add a Non-Steam Game → Johansson World (or Browse to ~/.local/bin/johansson-world).

The island comes with you

The world, character assets, ferry, interiors, shops, and Johansson Studio are installed locally. The game does not download its scenery while you play.

Your named save slots live in the application profile, with separate disk backups. Updating the application preserves progress.

Make yourself at home

☰ Menu → People lets you play as any of the 26 named residents. Each has a home and bed; families and housemates share addresses.

Money, inventory and quest progress are shared across residents; this is not 26 separate campaigns. Night-time starts follow the resident’s sleep and work schedule. ☰ Menu → Island → Go home takes you back to your own address.

Explore at your own pace

The current fighting system has been withdrawn. Conversations, apologies, peaceful festivals, dining and ferry travel remain. Active old combat saves recover safely; money, possessions, relationships and travel progress are retained.

The combat-dependent cave descent, cycling and storage-room minigames are removed. Actions show their full labels, and nights in both editions replace gecko beeps and the pulsing cricket recording with sparse natural textures.

Update from the game

Open ☰ Menu → Settings → Updates. When online, download the new build, then choose Save & restart.

0.2.7 installed patch support. Compatible earlier installations can use a changed-files patch when offered; the update screen shows patch/full package and size. Engine upgrades, skipped versions or a modified base use a full package. Files are verified before switching; saves and the previous installation are retained. The terminal installer remains a full install/repair download and prints the target version. Playing the installed island remains offline.

Controller guide

Controller loss pauses and opens Controls. Reconnect, release any held buttons, then press Menu when you are ready to resume. The game stays paused while you check the device; trackpad and keyboard controls remain available.

  • Left stick or left trackpad: walk · Right stick or right trackpad: look · A: interact · Y: Bag. The Field book is available inside Bag.
  • ☰ Menu: pause menu · B: back · View: town book.
  • D-pad down: hide or restore the HUD during exploration; navigate down in menus. Keyboard: F8 for HUD, F10 for pause.
  • Hold R2 to run · X to jump · R3 to level the camera · L2 to look closely.
  • ☰ Menu → Settings → Controls: adjust sensitivity, dead zone and field of view, or invert the camera. Live feedback tests both sticks and trackpads. The Deck axes and buttons are fixed.
  • Old saved remaps, swapped axes and disconnected controller choices are ignored without deleting them. Camera preferences and game progress remain. Controller activity hides the cursor; mouse movement/clicks restore it.
  • L1 zooms out during inspection; R1 drinks a held drink. D-pad up raises/lowers the pocket camera; A shoots, B lowers it. L3 is unused. Steam, Quick Access and rear paddles belong to Steam Input.
  • Prompts use Steam Deck symbols. Linux targets the Deck through Steam Input’s standard virtual gamepad; other Linux controllers are outside this release’s acceptance scope.
  • The pause menu includes Save and a confirmed Save & quit to Steam. L1/R1 changes sections; X quick-saves while paused.

Physical Steam Deck acceptance remains unverified. Automated tests check the installer’s configuration and simulated virtual gamepad output; they do not establish actual template loading, physical sticks or trackpad feel. Release evidence →

Remaining demo limitations

Optional AI-model downloads and external pages are blocked in the offline application. Editor tools and file/name dialogs may need a trackpad or keyboard. The compact town, unified ground and consolidated homes are included; the Minato Maru timetable is included. Board before the two-minute horn; remain aboard to walk the decks during the crossing and go ashore when access opens. The separate quick crossing remains available. Platform and troubleshooting

This release is for x86-64 Linux, including Steam Deck. It includes its own desktop runtime. Linux is the first development and testing platform. macOS, iPad and iPhone ports are planned; this download does not run on Apple devices or the ARM-based RG CubeXX.

Game files install under ~/.local/share/johansson-world/; application data and save backups normally live under ~/.config/Johansson World/. Custom XDG folders are respected. Keep your save directory when moving or reinstalling the game.

The browser edition remains an island showcase. In the browser, open Town book → Town tools → Player & save → Export save file. Import that file using Load → Import a save file in the installed edition.

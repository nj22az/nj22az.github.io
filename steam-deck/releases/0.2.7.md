# Johansson World Linux 0.2.7

For Steam Deck and x86-64 Linux. This is the full bootstrap update for smaller future patches.

- Subsequent compatible updates can download only changed files from the immediately previous release. Settings → Updates shows patch/full package and download size. Modified installations, skipped bases and engine changes use a full package. Checksums, complete file verification, separate staging and the retained previous version protect the update path. The terminal installer remains a full install/repair option.
- Fixed physical D-pad Down in pause/settings and in-game lists. It no longer acts like L3 or toggles the HUD behind a menu. Linux has one title controller handler, avoiding duplicate button actions.
- Back cancels a pending button assignment; Menu also cancels it. Hold Back for one second only when deliberately assigning that button. Existing custom controls are retained. How to play → Every button & context documents all controls with current controller symbols.
- Controller activity hides the mouse cursor across the interface. Deliberate mouse movement or a click restores it; idle controller drift does not steal it.
- The vending-machine application icon is launcher artwork, removed from the title/loading screen and pause header. The installer keeps the Linux desktop shortcut icon and prints its PNG path for Steam's shortcut artwork; existing Steam shortcuts may need their cached artwork selected again.
- Terminal installation/download output includes 0.2.7 explicitly.
- Exact spatial filtering speeds up town construction without removing scenery or changing the cel-shaded appearance. Local Mac/Chrome title readiness measured about 10.7 → 5.6 seconds; physical Steam Deck loading time has not been measured.

Default Steam Deck layout: left stick walk, right stick look; A interact/confirm, B back/stand/exit, X jump, Y Bag; R2 run, L2 look closely, R1 drink held drink, L1 inspect zoom out; R3 level view; D-pad left/right select nearby actions, up pocket camera, down HUD; View town book, Menu pause. In pause: L1/R1 tabs, X save. Camera: A shoot, B/up lower. Quarrels only: X punch, Y kick, hold A guard, B dodge, View leave. L3 is unused; Steam, Quick Access and rear paddles belong to Steam Input. PlayStation/Nintendo prompts follow the reported device and unknown pads show button positions.

Update from 0.2.6 via Menu → Settings → Updates or the website installer. This one update still downloads the full package to install the patch-capable updater. Saves and the previous installation are retained. Playing is offline; checking/downloading updates requires internet. Physical Deck performance, suspend/resume and hardware-controller acceptance remain pending. Editors and file/text dialogs may still need a pointer or keyboard. No 32-bit x86, ARM or Apple binary is included. The web game's behavior is unchanged.

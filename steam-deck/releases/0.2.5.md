In the installed app: Menu → Settings → Updates → Check for updates, then Download and Save & restart. This release remains a full verified download, compatible with 0.2.4. Small content-only patches are a future update format, not part of this release.

The Linux outline pass now runs at native resolution while retaining 4× MSAA and FXAA. This removes 36% of its scene-pass pixels versus the previous 1.25× internal scale, without changing walking speed or simulation time. A frame-rate gain has not been measured on physical Deck hardware.

The primary layout target is Steam Deck's 1280×800 display, retaining crisp modern text and controller navigation. The existing fixed-step simulation keeps game pace independent of refresh rate. Automated Linux startup and installer checks accompany this release; physical Steam Deck performance still needs testing.

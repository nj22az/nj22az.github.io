# Johansson World Linux 0.2.9

Integrates the browser world as of 19 October 2026 (main a0e0a25 with the graphics and loading fixes of PR #237).

- Every device draws the pre-18-October look again: 4× multisampling, HDR colour targets, shadows and detail streaming. The Linux edition keeps its native-resolution path (device pixel ratio 1, no supersampling) and its wider detail-stream limits.
- Lower memory for the same picture: static sign and plate canvases give their backing store back once uploaded; the Minato Maru's 232 engine-room plates are drawn and uploaded only with the camera inside the hull.
- Reduced graphics is a recovery mode only after two interrupted launches in a row, announced with a Restore full graphics button; a lost WebGL context no longer arms it.
- One honest loading bar: START is the bar until the island is built, walkable, compiled and drawn once; it never goes backwards and keeps moving through the town's build. The docks arrival shot no longer holds for streaming.
- Faster town build: power wires are tested only against meshes their span can reach (Main Street's wire spans are back); the buried garden ground is drawn as strips.
- Shiosai: pillow support, visible bedding and cabin framing.
- Preserves Linux controller mapping, Back/Menu cancellation, HUD isolation, playable residents, saved settings and profile data. Compatible 0.2.8 installations can receive a verified file patch; published versions are retained.

Release gates: desktop/controller/save/updater tests, production runtime build, simulated controller/menu and handheld-layout acceptance, native Ubuntu offline application/disk-save smoke, and public installer/checksum validation. These are automated checks, not physical Steam Deck acceptance or performance measurements. Hardware controller, suspend/resume, GPU performance and physical-device acceptance remain unverified.

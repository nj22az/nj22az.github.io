# Johansson World Linux 0.2.8

Integrates the published 0.2.7 controller and incremental-update improvements with the browser world as of 18 October 2026 (main 14a10d6).

- Compact Minato, consolidated occupied homes, Sakura main office with kitchenette and internal stairs, refined Shiosai houseboat, coordinated scenery and current indoor rendering/stability fixes.
- Preserves Linux controller mapping, Back/Menu cancellation, HUD isolation, playable residents, saved settings and profile data.
- Fixes a resident-selector crash caused by the removal of formerly vacant homes. Only characters with canonical households are playable; background figures do not displace residents.
- Retains the bounded mobile renderer and the Linux native-resolution rendering path.
- Compatible 0.2.7 installations can receive a verified file patch; modified/missing bases, skipped versions and changed Electron runtimes use the complete archive. Staging and saves remain separate; switching requires Save & restart. Corrupt patches do not switch versions.
- Published versions are retained rather than overwritten. 0.2.6 and 0.2.7 remain downloadable.

Release gates: desktop/controller/save/updater tests, production runtime build, simulated real-world controller/menu and handheld-layout acceptance, native Ubuntu offline application/disk-save smoke, and public installer/checksum validation. These are automated checks, not physical Steam Deck acceptance or performance measurements. Hardware controller, suspend/resume, GPU performance and physical-device acceptance remain unverified.

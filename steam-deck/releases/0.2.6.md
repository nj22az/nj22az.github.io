# Johansson World Linux 0.2.6

For Steam Deck and x86-64 Linux. This update carries forward 0.2.5’s approved Thuận, vending-machine app icon, clearer terminal installer and native-resolution Linux ink rendering.

- Y opens the actual Bag, matching Island → Bag. The Field book remains available inside Bag.
- Updates displays the running application version, read from Electron.
- Controller loss pauses and opens Controls through native hot-plug events, with polling fallback for Steam Input changes. Reconnecting or replacing the device keeps the game paused and ignores held confirm/back/Menu buttons until released. Pending button assignments cancel safely; saved mappings remain.
- Both bridge-wing doors show 操舵室 / WHEELHOUSE. The engine-room entrance retains its own sign.

Save before updating. Existing saves and custom controls are retained. Update via Menu → Settings → Updates, or run the website installer. Downloads are verified before switching versions and the previous installation is retained.

Automated controller/world and native Linux checks are linked from the release workflow and [demo guide](https://nj22az.github.io/linux-port/#demo-guide). Physical Steam Deck performance, battery life, suspend/resume and hardware-controller acceptance remain pending. Optional AI-model downloads/external pages are blocked in the offline app; editors and file/text dialogs may need a pointer or keyboard. There is no 32-bit x86, ARM or Apple binary in this release.

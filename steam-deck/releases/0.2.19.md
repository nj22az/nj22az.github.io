# Johansson World Linux 0.2.19

Brings the offline Linux edition up to the browser World of the evening of 24 October 2026, with Vy cel-shaded like the rest of the cast and an installer that puts the game in Steam's Gaming Mode with the Deck's Gamepad layout.

- **Vy.** Her head is cel-shaded like everyone else's instead of a shiny 3D head; the Soft sculpted head shape in Johansson Studio is cel-shaded too.
- **Make a face.** Moves → Make a face offers every face the painter knows, held for ten seconds; Neutral lets it go. The Moves text follows whoever you are playing.
- **The harbour noticeboard** is rebuilt from its drawings, with corrected flyer hours and map, and it opens the woodland diorama.
- **Cars and seats.** Moving cars stay solid, seated drivers no longer start conversations, and the bench that clipped through the harbour flowerbed is gone.
- **Steam Deck.** The installer adds Johansson World to your Steam Library and sets Steam Input to the Deck's Gamepad with Camera Controls layout, so the sticks and buttons control the game in Gaming Mode. Already installed? Run the installer with `--steam` in Desktop Mode. Steam closes for a moment while it is added.

Physical Steam Deck, Bluetooth-controller and iPhone acceptance remain unverified, including whether the Steam Input layout fixes controls on a real Deck. Version 0.2.18 and its assets are preserved.

Use the in-game Settings → Updates check or the published installer. Existing save profiles are retained. Release and software-acceptance evidence is recorded in `HANDOVER.md` (24 October 2026 session notes).

# Johansson World Linux 0.2.21

Steam Deck control update from production main `7c048393daaf614e242956cf3ee7b3f9bdc0f626`, retaining the published facial visibility correction.

- Fixed Steam Deck axes, buttons and prompts. Old saved remaps and disconnected device selections cannot swap or disable the sticks; saved game progress and camera preferences remain.
- Left stick and left trackpad move and navigate. Right stick and right trackpad look; right click centres the view. A confirms, B backs out, X jumps, Y opens Bag, R2 runs, L2 inspects, View opens the town book and Menu pauses.
- The installer supplies and selects an explicit local Steam Deck layout, retaining other games and backups. Linux no longer attempts raw-driver or other-controller compatibility in its Deck profile.

**Run the installer in Desktop Mode once to apply the trackpad layout**, then launch from Steam Library → Non-Steam. Existing installations can use `sh install.sh --steam` after updating the app. The in-game updater alone cannot apply Steam's layout while Steam is running.

Automated controller tests simulate Steam Input output. Physical Steam Deck acceptance and Steam's actual loading of the new template remain unverified. Other Linux controllers are outside this release's acceptance scope.

See `linux-port/acceptance-0.2.21.md` for release checks and evidence. Published 0.2.20 assets remain unchanged.

# JoJo Izakaya Tapper

Arcade tapper behind the cedar at **居酒屋ジョジョ**. You are **Nao**.

Pour at the tap, slide the drink, knock customers back toward the noren. Run the bar to catch every empty glass. Tips buy a kanpai.

**Live:** [nj22az.github.io/jojo-izakaya-tapper](https://nj22az.github.io/jojo-izakaya-tapper/)

W/S hop bars (wraps). A/D run the cedar. Space / Pour to fill and slide. Tap a bar to run there.

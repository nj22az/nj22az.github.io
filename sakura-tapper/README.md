# Sakura Tapper

Arcade tapper set in **Sakura Shōten**, the night konbini from Johansson Town.

Four tills. Hop with W/S or tap a lane, Space / Slide to send snacks, catch every empty tray. High score stays in this browser.

**Live:** [nj22az.github.io/sakura-tapper](https://nj22az.github.io/sakura-tapper/)

Static HTML, CSS, and a bundled Canvas 2D engine. No build step at runtime.

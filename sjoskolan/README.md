# Sjöskolan – elevmaterial

Publicerad kursöversikt för kalenderveckor 37–45. `vecka-XX/aktuell/` innehåller elevpresentationer och övningsstöd.

Presentationerna saknar lösningsbilder, anteckningar, kommentarer och dolda bilder. Genomräknade undervisningsexempel finns kvar. Inga separata prov, lärarfacit, kursböcker eller arkiv ingår.

Lokala lärarfiler är källmaterial och ska inte kopieras direkt hit. Uppdateringar behöver samma kontroll innan publicering.

# Byggunderlag för riggar

Genererar `sjoskolan/gemensamt/Riggar.html` med scheman (inline SVG), komponentlistor, säkerhet, driftsättning och riggdatablad.

```sh
cd sjoskolan/verktyg/riggar
python3 figs.py   # skriver figs.html med de fem schemana
python3 page.py   # skriver ../../gemensamt/Riggar.html
```

Kör `figs.py` före `page.py`.

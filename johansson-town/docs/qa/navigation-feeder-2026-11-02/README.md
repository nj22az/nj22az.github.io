# Navigation feeder source-geometry proofs

Reproduce with `node tools/export-bridge-lantern-review.mjs`, then Blender `tools/blender/review-minato-bridge-lantern.py`.

The three PNGs combine the actual World bridge geometry, newly exported native feeder and existing navigation lantern position. Runtime lever meshes are exported from the actual game builder. Blender text reproduces the panel canvas text at matching world positions. These are Blender source-geometry review images, not browser screenshots or physical-device evidence.

The intermediate `bridge-source-geometry.json` is reproducible and is not committed. See [source handover](../../../briefs/HANDOFF-NAVIGATION-FEEDER-2026-11-02.md) for topology, tests and verification limits.

# Urban island boundary

This supersedes the rural-preserving boundary in the architect-masterplan revision.
The main island now contains the port, shopping streets, residential blocks and
Harbour Park with Umi-no-yu. Rural and farming work is deferred to the tropical
island; no new rural content is added there in this revision.

The land polygon shrinks from 37,280.375 to 11,703.125 square metres (68.6%).
The northern boundary stops at z=95, including the two existing northern houses.
Its shoulder follows the occupied two-row residential grid, rather than extending
an empty rectangle to the former fields. Northern roads, mountain, forest, farms,
Fumoto, Hoshizaki, lighthouse and their active paths, collisions, home entrances,
map destinations, guide entries and feed photo destinations are removed.

All 43 retained building plots retain their tested public circuits. The 2.4 m
coastal walking loop closes around the compact urban area. Fujita's timber access,
the existing harbour and the separate tropical-island ferry remain operational.

`plan.png` is an exact source-plan drawing, not a gameplay screenshot. Browser
visual acceptance remains unavailable because this environment cannot start WebGL.
The live scene geometry is tested for continuous floors, collision clearance,
full-width land support and connectivity to Main Street, including the complete
coastal loop. Removed rural locations are explicitly tested as sea without routes,
meshes, colliders or map targets.

# Generated Japanese voice pilot

Four 24 kHz mono PCM WAV clips were generated on 2026-09-08 using the public [Qwen/Qwen3-TTS Space](https://huggingface.co/spaces/Qwen/Qwen3-TTS), selecting the [Qwen3-TTS-12Hz-1.7B-CustomVoice model](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice). The model card declares Apache-2.0. No model weights are distributed here; this is model attribution, not a claim that model licensing automatically licenses generated outputs.

The Japanese scripts and English subtitles are original project writing. These are synthetic performances using the model's supplied Ono_anna and Aiden voices; no recording of a real person was uploaded or cloned. No music or sampled broadcast is included. The existing CC0 dedication for signal-generated town sounds does **not** cover this folder. These files are project-generated outputs, not a third-party CC0 pack.

Each `.source.json` records the exact generation request and returned event identifier. Exact output hashes, duration, sample rate and amplitude checks are in `../../generation/pilot/audio-validation.json`. Generation is stochastic; the request alone does not guarantee byte-identical regeneration. The hosted service did not expose the loaded weight revision in its generation response.

Completed: Aiko greeting, Tama subject, window chair; Kenji Star Port subject. Six further authored lines remain pending because the public ZeroGPU quota was exhausted. Native Japanese pronunciation review and rendered-game listening remain pending. The Aiden preset is English-native and especially needs Japanese listening review.

Playback is local and on demand. The current dialogue subtitle remains available if sound is muted, unavailable or a file fails to load. Closing a dialogue, changing its subject, muting sound or hiding the page cancels speech.

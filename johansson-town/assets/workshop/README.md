# Form 3D workshop patterns

Generated from `form-3d-studio/src/open-models.mjs` at repository base commit
`902fc901558e89e450a7857dab8834099f24d486` using the parameters in
`src/workshop/catalogue.js`. Source recipes: Form 3D Studio contributors, 2026,
MIT. JSCAD 2.13.0 generates the original solids; meshoptimizer reduces the game
display meshes. The existing Johansson capsule wordmark is retained.

Reproduce with `node scripts/build-workshop-models.mjs`. These simplified JSON
meshes are used only for game display. The original application retains its
full geometry and manufacturing exports.

The source licence and JSCAD notice are preserved in `LICENSE.txt`.

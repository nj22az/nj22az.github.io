# Yui — Sakura Shōten clerk

Original adult clerk, age 26. Pink cotton, cream collar and hat, rose glasses, ribbons and dark loafers. `yui.blend` is the packed editable Blender 4.2 source; the PNGs are actual renders of the reduced export, not game screenshots. The GLB is in `assets/characters/realistic/yui.glb`.

Rebuild using `tools/blender/build-yui.py` then `tools/blender/export-yui.py` with the same arguments as the Kenji pipeline. The selected MakeHuman CC0 source files and hashes are listed in `assets/characters/realistic/yui-provenance.json`; full licence text is alongside it. Collar, glasses, hat and ribbons are original authored geometry. See `docs/SAKURA_STORE.md` for store interactions and the disabled Shopify adapter.

Motion is a scripted first pass. Face, hair, cloth deformation and store lighting need an in-game visual review before release.

## Working recipe (learned the hard way)

- **Worktrees.** Use one worktree per job under the session scratchpad. Symlink `node_modules` from the main checkout
  and never commit symlinks: `git ls-files -s | awk '$1=="120000"'` must be empty.
- **Runtime.** Rebuild with `npm run build:runtime` in `johansson-town` and commit `runtime/`, `index.html` and `sw.js`
  last. When merging main:
  1. `git rm -r --cached johansson-town/runtime`, then `rm -rf` it;
  2. `git checkout origin/main -- runtime index.html sw.js`;
  3. rebuild;
  4. re-apply any `index.html` lines the branch needs. Never take main's `index.html` blindly: the quiet HUD's
     stylesheet was once lost that way.
- **Merging.** Codex merges to main too: fetch before merging and expect runtime conflicts.
- **Before anything visual reaches the owner.** Check photos at 390×844 with the `?audit` harness (Chromium
  `/opt/pw-browsers/chromium`, swiftshader).
- **Visual changes** merge only after the owner has seen before/after photos.
